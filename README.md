# Frogger Game

This is a simple frogger game, that is made via tutorial by [Clear Code](https://github.com/clear-code-projects).

# How to launch game

There are two ways to launch this game on your Windows or Linux system:
1. Just download .exe or .x86_64 file from release page.
2. You can download this repository and then launch it, using Godot 4.0 or higher.

# How to play

You can move your character via WASD or arrow keys, and restart game with spacebar. Your task is just reach the end of the map with less time.
